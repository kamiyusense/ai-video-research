# 外部AIに貼る：字幕・公式調査担当（Gemini Spark等）
`{{YOUTUBE_URL}}` と `{{USER_QUESTION}}` を置き換える。相手の映像担当の結果は**独立調査完了まで渡さない**。

```markdown
# 📺 AI技術研究室：独立調査担当
対象動画：{{YOUTUBE_URL}}
一番知りたいこと：{{USER_QUESTION}}

YouTubeの利用可能なメタデータ・字幕/文字起こしを確認し、動画の主張を独自要約してください。
映像を直接取得できなければ「映像未確認」と明記し、操作画面を見たと推測しない。

次に、動画から独立して公式一次資料（製品・API・価格・規約・公開実装・論文）を優先して照合してください。
動画が公開された当時の説明と、現在の最新仕様は別々に書いてください。
先駆者の工夫、失敗例、代替手段、必要コスト・対応プランを確認できた範囲で比較してください。

【出力】
1. 動画の独自要約（短く）
2. 要点と確認した動画時刻（最大7点）
3. 主要主張別の一次資料URL・資料の日付・確認日・判定
4. 利用者報告（逸話）と客観的な実験結果の区別
5. 再現条件・料金・リスク・代替策
6. 動画の内容にない独自の提案・解釈（別枠）
7. 映像・字幕・資料の実際の取得範囲とUNKNOWN

根拠なしに成功率・平均利益・失敗の頻度を数値断定しない。
法律・行政処分・規約を扱う場合は公式資料から「処分種類・日付・対象」を正確に照合し、疑わしければUNKNOWN。
検索結果・動画のタイトルだけで本編確認済みと書かない。
外部書込み、GitHub、課金、権限変更、APIキー変更、LIVEモデル起動は禁止。
```

# 担当一覧（汎用5役割）
| 役割ID | 仕事 | 主な入力 | 次の担当 |
|---|---|---|---|
| coordinator | 受付、目的の確認、重複確認、担当の割り当て | ユーザーの依頼、台帳、索引 | specialist-a / specialist-b |
| specialist-a | 案件ごとの主たる実務・調査・制作 | タスク、資料、受入条件 | reviewer |
| specialist-b | 独立調査・検証・代替案（不要なら省略） | 同じ課題を独立して検討 | reviewer |
| reviewer | 根拠、矛盾、安全、受入条件の検品 | A/B報告、証拠 | archivist / coordinator |
| archivist | 重複なしの記録、索引更新、読み戻し | 検品済み成果、保存許可 | coordinator |

## 役割はツールではない
5つのAI契約、別プロセス、常時接続、タスクの自動発送は必要条件ではない。
ChatGPT、Claude、Gemini等のどれが各担当を担うかはプロジェクトごとに決める。
AIがGitHubのprivate情報を読めるとは決めつけず、接続・認証・権限を確認する。
独立レビューを求める場合、元担当の自己判定だけを独立検品と呼ばない。

## カスタマイズ例
- 動画研究: A=映像、B=字幕/公式資料。
- 開発: A=実装、B=独立試験/設計調査。
- 企画制作: A=制作、B=根拠調査/編集。
名前や担当数を変えたらファイル間のリンク、受渡し先、タスク索引を同時に更新する。

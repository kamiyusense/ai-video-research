# 導入ロードマップとゲート
## A: テンプレート準備（STATIC）
- ひな形ファイルとリンク・重複・安全境界の静的検査。
- 既存プロジェクトへの移植は別途承認。対象既存ファイルの上書き禁止。
## B: 小規模手動実地試験
- 既存タスク1件の受入 → 専門担当 → 検品 → 記録の受渡し。
- 同じtask_idの二重登録なし、新チャットで再読込できることを確認。
- 認証・費用・権限・ユーザーのコピペ回数・復元失敗を計測。
## C: 半自動化の調査
- 利用可能なWork/Claude/Gemini等で実行可能な操作を事前に確認。
- 人間の承認位置、外部送信範囲、二重起動防止、失敗復旧、費用上限を設計する。
- 実装・LIVE・自動起動は別承認。テンプレート化だけで配線済みとしない。

初期状態：Aのひな形を保存しただけ。BとCはNOT_RUN/NOT_WIRED。

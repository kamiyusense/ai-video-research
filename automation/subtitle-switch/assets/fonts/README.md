# Title fonts

Subsets of six Google Fonts families, containing only the glyphs of the app name
「AI動画字幕図書館司書猫さん」. The app picks one at random for the title on each launch.
Owner choice (2026-10-27): A Zen Maru Gothic Black, C Kiwi Maru Medium, F Dela Gothic One,
G Hachi Maru Pop, H DotGothic16, J Potta One.

Source: https://github.com/google/fonts (ofl/ folders), subset with fontTools `pyftsubset`.
License: SIL Open Font License 1.1 for each family (see the OFL-*.txt files next to the fonts).
If the app name changes, the subsets must be regenerated from the original fonts.

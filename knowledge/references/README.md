# 参考資料ノート（REFERENCE_NOTE）

動画以外の参考資料（Xのポスト・記事、ブログ、GitHub、知人の資料など）を、検索しやすいOKF荷札つきの要約として置く場所。書き方は `automation/reference-okf/SKILL.md` に従う。

- 本文は要約だけ。原文の全文は保存しない（このリポジトリは公開）。
- 知人の非公開資料は、URL・持ち主のメールアドレスを書かない。
- `content_status` で「自分で読んだ」か「他のAIの要約だけ」かを区別する。
- 動画の研究ノートとの関係は `related_records` に CANDIDATE / CONFIRMED で書く。

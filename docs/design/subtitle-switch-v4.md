## 採用する見た目の方針

白からごく薄い灰色の地、濃い灰色の本文、広めの余白。カードは14px角丸、薄い境界と柔らかい影。赤は保存・チャンネル再生マーク・チェックと指定された見出し文字に使う。
本文・表・入力・ボタンは `"Yu Gothic UI", "Meiryo UI", sans-serif`。見出しだけ同梱6書体から起動ごとにランダム選択し、クリック（キーボードでも操作可）で次へ切り替える。
「AI動画字幕」は濃い灰色、「図書館司書」「さん」は赤。「猫」は橙の丸と緑の葉の前に白文字・黒の太いフチで重ねる。見出しは上下に余白を取り、蜜柑を切らない。
保存は12〜14px角丸の赤い縦グラデーション＋濃い赤の帯状の影。hoverで明るく、押下で3px沈む。副ボタンは淡い背景と意味色の線・アイコン。動きは短く、`prefers-reduced-motion` を尊重する。

```text
│ □ │ チェックした行のみ薄い赤                                         │
│    一覧領域だけ縦横スクロール、見出し固定                             │
├──────────────────────────────────────────────────────────────────────┤
│ 弾く理由 [選択／入力] [弾く] [戻す] [一覧を更新]  □弾いた □完了済み  │
│ 再開時の原因 [選択]                                                  │

└──────────────────────────────────────────────────────────────────────┘
                 質問ボタン → 質問・回答のパネル
```

初期窓は1280×840程度（1920px画面の約67%）、Edge/Chromeの `--app` と `--window-size`。小画面ではCSS gridの `minmax(0, 1fr)` で一覧を先に縮める。
下部操作は一覧の外に置き、画面高に応じて余白・URL欄を縮める。狭い画面では操作欄を折り返す。極端に低い画面でも保存ボタンは固定の末尾領域に残し、補助操作には独立スクロールを設ける。
質問パネルも一覧・操作欄の高さを押し出さないオーバーレイとし、閉じる操作と内部スクロールを持つ。

## ローカルWebと既存処理のつなぎ方

`subtitle_switch.pyw` の起動入口と `switch_app.main()` をローカルWebへ切り替える。`services.py`、`pipeline.py`、`switch_state.py`、`metadata.py`、`ask_research.py` の動作は変更しない。
`switch_app` の `folders`、`display_row`、`save_targets`、`save_session` 等は既存の契約として使い、短い表示と全文tooltipの組をWeb用アダプターで作る。状態の真実はInventoryに置く。
起動時に受け箱とメタデータを読み込む。以後の一覧更新、弾く、戻す、対象決定、保存、質問は明示の操作から実行する。保存・質問はバックグラウンド実行とし、進行中の重複操作を拒否する。既存 `InstanceLock` を保持し、終了まで同一状態フォルダの二重起動を防ぐ。
旧tkinter画面は呼出不能にして削除する方針。純粋な表示・対象計算関数、既存試験が参照する互換ユーティリティ、旧PowerShell試作の移行用コードは残す。画面の二重保守を避け、移行の無関係な経路を壊さないため。

## サーバーと起動の安全設計

- 標準ライブラリ `http.server` を `127.0.0.1` とOS割当ポートにのみbind。固定ポートやLAN公開なし。
- 起動ごとに `secrets` で合言葉を作る。初期URLに付与し、以後のAPI・静的素材要求にも付ける。比較は定数時間比較。リクエスト行を含むアクセスログを出さない。
- `Host` は実際の `127.0.0.1:<port>` と完全一致のみ許可。localhost・別ポート・欠落・重複を拒否。
- 状態GET、変更POST。GETでは保存・質問・チェック等を変更しない。未知の操作・大きすぎる入力・不正JSONを拒否。
- CORSを許可しない。POSTはJSONと合言葉を必須にし、存在するOriginは同一originのみ許可。OPTIONSは拒否。外部サイト・DNS rebindingからの操作を防ぐ。
- Web部品はHTMLへ埋め込み、素材取得はフォント・猫フォルダのPNG/TTFだけに制限。traversal・symlink越境を拒否。レスポンスはno-store、nosniff、referrerを送らない設定。HTMLに外部接続不要のCSP。
- ブラウザはWindowsの既知のEdge/Chromeインストール位置を探す。`Popen` に既存方針の `CREATE_NO_WINDOW`。見つからなければ既定ブラウザへ、起動失敗時も無限再試行しない。
- 画面は数秒間隔で心拍。窓を閉じて心拍が途絶えたら猶予後に終了する。起動失敗もタイムアウトで終了。処理中の保存を途中で切らず、完了後にサーバー・lockを解放。実処理を再送しない。

## 猫の状態と遊び

全身・顔とも `manifest.json` のframe数・fps・loop・hold_lastを使用。待機idle、処理中walk、成功done、失敗／要確認error。新しい操作でフレームを初期化し、done/errorは最後で停止。全身walkは右から左へゆっくり移動し、左端を抜けたら右に戻る。
遊びの近接範囲は **猫の中心から220 CSS px以内**。角度は `atan2(dy, dx)` を45度単位で丸め、右=0、時計回りの8方向にする。
中心からmanifestの `punch_radius_px` 以内なら左／右のパンチを1回再生。再生中は上書きせず、開始時刻から `punch_cooldown_sec`（欠落時0.6秒）までは再発火しない。離れて3秒で状態の顔へ戻る。
処理中・エラーを遊びで隠さないため、状態ラベルを顔の隣に常設する。`cat_play` がない／壊れている場合は状態顔だけと通常カーソルへ戻す。フレーム寸法は各manifestに従う。
猫じゃらしカーソルは画面内だけに指定し、hotspotはmanifestから読む。ボタンはpointer、入力・textareaはtextに戻す。素材未存在時にはcursor URLを設定しない。

## ラウンド3：見本からの発展（2026-10-27）

実装前に `.symphony/design_mock.png` を画像として確認した。見本から受け取ったのは、白い一覧を中心に淡いグレーの区画と赤い操作を置く、明るく整理された仕事画面という印象。見本の構図や絵を複製せず、赤を重要な操作と状態に絞り、文字の強弱・整列・余白で一覧の読みやすさを高める。幅の狭い窓でも情報を読めるよう、列の短縮と横スクロールを使い、重複する操作を減らす。

画面方式は引き続き tkinter/ttk とする。ローカル HTML/CSS/SVG は文字やアイコンの表現に優れる一方、既存の保存・安全停止・読み戻し・二重起動防止をブラウザから操作するためには、127.0.0.1 限定のサーバーと起動ごとの認証を含む新たな境界が必要になる。今回は既存の処理境界を維持でき、標準ライブラリの画像描画と部品の調整で改善できる tkinter を選ぶ。Windows の各表示倍率での実画面は UNKNOWN、オーナーによる確認が必要。

## 画面方式

既存の tkinter/ttk を採用する。標準ライブラリで配布でき、既存の保存・停止・読み戻し処理を保てる。Treeview の先頭列をチェック表示として扱い、選択状態は行選択と別に持つ。候補のローカル HTML/CSS/SVG + http.server は角丸やベクター表示に優れるが、ブラウザとローカルサーバー間の操作・停止境界を作り直す量が大きく、今回は採用しない。追加パッケージは不要。

## 配置と外観

```text
[本と鉛筆] AI動画字幕図書館司書さん             [設定]
[一覧を更新] [全部選ぶ／全部外す]    状態・説明
[✓ | 動画 | チャンネル | 公開日 | 言語 | テーマ | 工程 | 状態 | Notebook]
[一覧（縦横スクロール）                                            ]
[手動保存] [選択保存]        [きらめき 保存した動画内容をAIに質問 ロボット]
```

白・淡いグレーの背景、YouTube を思わせる赤のアクセント、余白を広く取る。Yu Gothic UI、代替 Meiryo UI を使い、フォント実測と DPI に基づく行高・余白・最小幅を設ける。tkinter の角丸は画像描画で実現し、文字を描画領域で切らない。100/125/150% の Windows 実表示はオーナー確認待ち。

## アイコン

再配布素材や公式ロゴを使わず、標準ライブラリの描画で独自に高解像度で作り縮小する。同じ本と鉛筆を窓・保存・見出しに使う。開いた本と右側の白い鉛筆は隙間を設けて重ならない。歯車は円周上に等間隔の歯、戻す・更新は均一幅の円弧と矢印。きらめきは橙、ロボット顔は黒の独自図形。生成手順もリポジトリに保存する。

## データと状態

一覧更新時、既存受け箱の値とローカルキャッシュを優先し、未取得のチャンネル・公開日・言語のみ yt-dlp の情報取得で補う。動画や字幕はダウンロードしない。ワーカーで逐次取得し、リクエスト間隔は最低 2 秒、成功値を保存する。取得失敗は理由を表示し、失敗を成功値としてキャッシュしない。テーマは受け箱の値か「未設定」。Notebook 数は工程前・未接続・読み取り失敗・数値を区別する。弾いた行はチェック不可、保存対象はチェック済みの有効行だけ。

## AI 質問と安全

明示的な送信ボタンのみで実行。複数行の質問は最大 2,000 文字、`research/` の保存済みノートを既存 `query_research.py` の検索結果に基づいて最大 3 件、合計 24,000 文字まで送る。字幕全文や他のディレクトリは送らない。根拠のファイル名と実際にノートに存在する時刻リンクを提示し、無ければ UNKNOWN とする。Claude CLI の既存 API キー停止機構を再利用し、サブスクリプションログインを使う。送信内容と回答をローカル状態フォルダに UTF-8 で記録する旨を画面と README に示す。質問・ノート・回答は外部送信やローカルログに含まれるため、利用者が内容を確認してから送信する。Grok は Windows とキー不要のサブスクリプション利用条件を未実証のため無効、理由は UNKNOWN と画面と README に記す。自動送信、実モデル実行、API キー利用は行わない。

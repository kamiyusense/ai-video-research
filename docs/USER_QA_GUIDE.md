# AI技術研究室｜研究成果・動画検索 日常利用ガイド (`USER_QA_GUIDE.md`)

AI技術研究室で蓄積・検証された動画研究知見（28動画・241チャプター）を、日常の作業や調査で安全かつ快適に活用するための総合ガイドです。

---

## 1. 4つの利用経路 比較評価（8基準）

ユーザーの利用環境や目的に応じて、4つのアクセス経路を選択できます。

| 評価基準 | 経路A: ChatGPT/Custom GPTs連携 | 経路B: ローカルCLI/対話モード (`query_research.py`) | 経路C: Gemini Notebook (元資料の図書館) | 経路D: 軽量ワンライナー・シェル連携 |
| :--- | :--- | :--- | :--- | :--- |
| **① 応答速度** | 中（3〜10秒） | **極めて高速（0.5〜1秒・ローカル完結）** | 中〜低（5〜15秒、ソース横断検索） | **極めて高速（1秒未満）** |
| **② 正確性・ハルシネーション耐性** | 中（要約時に独自解釈・幻覚のリスク） | **最高（完全決定論的・契約スキーマ厳格）** | 高（Notebook内ソースを直接引用） | **最高（完全決定論的・フィルタ抽出）** |
| **③ 再生リンク・時刻根拠の透明性** | 低（推測URLや幻覚時刻を生成しがち） | **最高（4種Provenance・未検証は無リンク厳格）** | 中（動画内再生位置の直接リンクは非対応） | **最高（検証済みのみURL出力）** |
| **④ 導入コスト (API・課金・環境)** | OpenAI Plus契約等が必要 | **ゼロ（標準Python/ローカル実行、API不要）** | **ゼロ（Googleアカウントで無料枠利用可能）** | **ゼロ（追加依存なし）** |
| **⑤ 保守性** | ナレッジの手動再アップロードが必要 | **最高（Git pullで常に最新知見が即座に反映）** | ソース追加やノート同期の手動メンテが必要 | **最高（リポジトリ同期のみ）** |
| **⑥ 拡張性** | GPT Store公開や他メンバー共有が容易 | スクリプト連携、CI/CD、バッチ処理に最適 | 音声概要生成やマインドマップ等の独自機能 | パイプライン処理、FZFやfzf連携 |
| **⑦ モバイル・外出先利用** | **最適（ChatGPTスマホアプリから利用可能）** | 不可（PC環境が必要） | **最適（スマホブラウザからGemini Notebook閲覧）**| 不可（PC環境が必要） |
| **⑧ 非エンジニア親和性** | **最高（自然なチャットUI）** | 中（ターミナル操作が必要、対話モードで緩和） | **高（ウェブUI、カード形式）** | 低（コマンドラインに慣れた人向け） |

### おすすめの使い分け

- **PC作業中・開発中（推奨: 経路B）**:
  ターミナルで `python automation/gemini-notebook/query_research.py -i` を立ち上げておき、気になる概念や「これってどの動画で言ってたっけ？」を即座に引く。ハルシネーションゼロで、検証済み時刻だけが返るため最も確実。
- **スマホ・移動中（推奨: 経路C または 経路A）**:
  外出先で動画やまとめを振り返りたいときは、ブラウザから Gemini Notebook を開いて質問するか、ChatGPT に `video_knowledge_catalog.json` を参照させる。
- **じっくり論文・長尺動画を深掘りしたい時（推奨: 経路C）**:
  Gemini Notebook のチャットで特定の動画ソースを指定し、詳細な議論や周辺知識を質問する。

## 2. 各経路の具体的な利用手順

### 経路B: ローカルCLI / 対話モード（PC利用・基本）

ローカルPCで最も手軽かつ正確に検索できる方法です。APIキーも外部通信も不要です。

#### 1. 対話モードの起動
```bash
py -3 automation/gemini-notebook/query_research.py -i
```
（または PowerShell で `.\run_qa.ps1` を実行）

#### 2. 質問の入力
起動すると対話プロンプトが表示されます。日本語でそのまま質問してください。
```text
============================================================
AI技術研究室 | 自然言語Q&A・動画チャプター検索 (対話モード)
質問を入力してください ('exit', 'quit', 'q' で終了)
============================================================

質問 > ハーネスって何？どの動画を見ればいい？
```

#### 3. 結果の確認
質問の意図（概念、失敗例、手順など）が自動判定され、以下の4ブロックで回答されます：
1. **質問の分析結果**（判定された意図、検出された専門用語）
2. **最適な動画チャプターと再生リンク**（検証済み時刻のみYouTubeリンク付き、未検証は `UNKNOWN` 明示）
3. **Gemini Notebook での深掘りガイド**（該当動画のNotebookソースID、深掘り質問プロンプト案）
4. **未確認の課題・次の調査候補**（未解決課題P006やUNKNOWN区間）

終了するときは `exit` または `q` を入力します。

#### 4. 単発の質問（ワンライナー）
対話モードに入らず1問だけ引くことも可能です：
```bash
py -3 automation/gemini-notebook/query_research.py -q "AIエージェントの失敗例や暴走を防ぐガードレールは？"
```

JSON形式で結果を取得し、他のスクリプトに渡す場合：
```bash
py -3 automation/gemini-notebook/query_research.py -q "CursorのHooks設定" --json
```

### 経路A: ChatGPT / Custom GPTs連携（スマホ・日常チャット）

ChatGPT（Plus等）で日常的に本研究室の知見を活用する方法です。

1. **ナレッジファイルの準備**:
   リポジトリ内の最新カタログファイル `automation/gemini-notebook/state/video_knowledge_catalog.json` を取得します。
2. **Custom GPTの作成**:
   - GPT Builder の Knowledge に `video_knowledge_catalog.json` をアップロード。
   - Instructions に以下を指定：
     > 「あなたはAI技術研究室のナレッジアシスタントです。添付の `video_knowledge_catalog.json` に基づいて回答してください。
     > 時刻が `UNKNOWN` の箇所には絶対にYouTubeリンクを創作・推測せず、『時刻未検証』と明記してください。
     > `start_seconds` が存在するチャプターのみ再生リンクを案内してください。」
3. **スマホアプリから質問**:
   外出先から「Claudeのハーネスの基本動画教えて」と話しかけるだけで、カタログに基づく確実な回答が得られます。

## 4. 再生リンクと時刻根拠（Provenance）の重要ルール

本システムでは、**「推測による再生リンクの自動生成」を厳格に禁止**しています。

チャプター情報には、以下のいずれかの根拠（`timestamp_source` / `provenance`）が明記されています：

1. **`TIMESTAMPED_CAPTIONS`**
   - **根拠**: YouTube公式の字幕（Timed Text）とチャプター内容の決定論的トークン一致により検証済み。
   - **リンク**: 有効（`&t=XXs` 付き）。
2. **`YOUTUBE_CHAPTER_METADATA`**
   - **根拠**: YouTube動画概要欄の公式チャプター定義から抽出。
   - **リンク**: 有効（`&t=XXs` 付き）。
3. **`VISUAL_FRAME_CHECK`**
   - **根拠**: 過去のGoogle AI Studio等による映像実演のフレーム確認報告（※AGYが直接動画を視認したものではなく、ユーザー報告由来の検証）。
   - **リンク**: 有効（`&t=XXs` 付き）。
4. **`UNKNOWN`**
   - **根拠**: 時刻が未検証、または字幕・映像との客観的照合が未完了。
   - **リンク**: **無リンク（推測リンク生成を防止）**。
   - 画面には `[時刻未検証 (UNKNOWN)]` と表示されます。動画URLのみ案内され、秒数ジャンプは行われません。

> [!IMPORTANT]
> 検索結果で再生リンクが付いていないチャプターは、バグではなく**安全のためのガードレール**です。「適当な再生位置に飛んで誤解を生むこと」を完全に防止しています。
